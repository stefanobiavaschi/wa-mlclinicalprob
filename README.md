# wa-mlclinicalprob  

This repository contains the code for the web application used to deploy various versions of the classification model developed in the project [MLClinical_ABG](https://github.com/stefanobiavaschi/MLClinical_ABG).  

You can access the web app at the following link:  

[wa-mlclinicalprob](https://wa-mlclinicalprob-tesi-codazzi.streamlit.app/) (Due to the use of a free version, the app may be "dormant" and may take a few minutes to activate)
